# Pocket Timer

A tiny command-line timer for focused work sessions.

## Install

```sh
npm install -g pocket-timer
```

## Usage

```sh
pocket-timer 25m --label "Write docs"
```

> [!TIP]
> Run `pocket-timer --help` to see every option.

## Features

- A countdown with a progress bar
- A desktop notification when the time is up
- A history of your sessions
