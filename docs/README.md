# Documentation

This is the entrance to the documentation: start with "Get started", follow a guide for what you want to do, and look things up in the reference.

## Get started

- [Get started](./getting-started.md): publish your README as a site in three steps.
- [Preview locally](./preview.md): check the look and the links on your own computer before you push.

## What you want to do (guides)

- [Guides](./guides/README.md): add pages, change the look, support more than one language, use your own domain, update, and set up how links look when shared.

## What you want to look up (reference)

- [Reference](./reference/README.md): settings, frontmatter, commands, how the build works and the features of a page.
- [Reference for AI agents](./ai-reference.md): one page to paste into an AI agent so that it sets Tsuzuri up for you.

## When you are in trouble

- [FAQ](./faq.md): answers to the common problems.

## Contact

- [Contribute & contact](./contact.md): ask to list your style in the gallery, or send a question or a wish, as a GitHub issue.
