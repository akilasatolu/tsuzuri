# Contact

Questions, wishes, and requests to list your style in the style gallery are all received as GitHub issues.

<p class="tsuzuri-hero-actions"><a class="tsuzuri-button tsuzuri-button-primary" href="https://github.com/akilasatolu/tsuzuri/issues/new">New issue</a><span class="tsuzuri-sep"> · </span><a class="tsuzuri-button" href="https://github.com/akilasatolu/tsuzuri/issues">All issues</a></p>

Tsuzuri is maintained by one person. Issues are the one place where requests are received, so please start there.

## Questions and wishes

For a question, a problem or a wish, open a [new issue](https://github.com/akilasatolu/tsuzuri/issues/new) and write the following, as far as you can.

- What you did, what you expected, and what happened instead.
- The version of Tsuzuri and the command you ran.
- The part of `.github/tsuzuri/config` that is related.

Before you write, a look at the [FAQ](faq.md) and the existing [issues](https://github.com/akilasatolu/tsuzuri/issues) may already answer it.

## Get your style listed in the style gallery

If you made a custom style and want it shown in the [style gallery](../gallery/style-gallery.md), open a [new issue](https://github.com/akilasatolu/tsuzuri/issues/new) with the following.

- **Name**: the name of the style, in English.
- **URL**: a page to link from the style's page (for example, a site that uses the style, or the repository of the style).
- **Images**: one to three screenshots (they are shown as a slider on the tile).
- **Description**: one line about the look.
- **Permission**: whether the images and the CSS file may be added to this repository (`assets/gallery/`). They are hosted here, not linked from your site.

If it is accepted, the maintainer adds a tile and a page for your style to the style gallery. The tile shows your images as a slider, and a click opens the style's page, where the CSS file can be downloaded.
