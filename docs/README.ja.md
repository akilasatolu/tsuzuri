# ドキュメント

ここはドキュメントの入口です。「はじめる」から読み、やりたいことはガイドで、調べたいことはリファレンスで探します。

## はじめる

- [はじめる](./getting-started.ja.md): READMEをサイトとして公開する、3つの手順。
- [手元で確認する](./preview.ja.md): pushする前に、自分のパソコンで見た目とリンクを確かめる。

## やりたいこと(ガイド)

- [ガイド](./guides/README.ja.md): ページを増やす・見た目を変える・複数の言語に対応する・独自ドメインにする・更新する・シェアされたときの見え方を整える。

- [リファレンス](./reference/README.ja.md): 設定・frontmatter・コマンド・ビルドの仕組み・ページの機能。
- [AIエージェント向けの参考情報](./ai-reference.ja.md): AIエージェントに貼り付けるだけで、Tsuzuriの導入を任せられる1ページ。
