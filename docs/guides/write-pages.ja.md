# ページを書く

ページを増やすには、READMEか、すでにサイトにあるページから、そのページへのリンクを1つ足します。これだけで、そのページがサイトに加わります。

## リンクでページを増やす

Tsuzuriは`README.md`を起点に、リンクをたどります。リンクをたどって届いたページとファイルだけが公開されるので、どこからもリンクされていないMarkdownファイルは、サイトに載りません。画像やほかのファイルも同じで、埋め込んだり、リンクしたりしたものが、一緒にコピーされます([ビルドの仕組み](../reference/how-it-works.ja.md)に詳細があります)。

```markdown
[ガイド](docs/guide.md)を見てください。
```

## フォルダとナビ

リポジトリのフォルダが、そのままナビとURLになります。`docs/guide.md`は`docs/guide.html`として公開され、ナビでは「docs」のグループに入ります。フォルダの中の`README.md`(または`index.md`)が、そのフォルダの入口になります。

並びを決めるには、frontmatterに`order`を書きます。`order`があるページが先に、小さい順に並び、ないページは、リンクが見つかった順にその後に続きます。フォルダの位置は、その中の`README.md`の`order`で決まります。`nav: false`を書いたページは、ナビに載りません(リンクからは開けます)。

## 画像とファイル

画像やファイルは、ふつうのMarkdownで書きます(`![ロゴ](assets/logo.png)`、`[マニュアル](docs/manual.pdf)`)。よく使う画像・PDF・動画・アーカイブのファイルはサイトにコピーされ、ソースコードや設定ファイルなどは、GitHub上のファイルへのリンクになります。一覧は[ビルドの仕組み](../reference/how-it-works.ja.md)にあります。

## 見出しと目次

ページの見出しが、ナビを表示しているときの目次になります。見出しにはidが付くので、`[手順](guide.md#手順)`のようにリンクできます。`STRICT_LINKS=true`のときは、存在しない見出しへのリンクがあるとビルドが止まります。

## frontmatter

ページの先頭に、いくつかの設定を書けます。よく使うのは`title`・`description`・`nav`・`order`で、すべてのキーは[Frontmatterリファレンス](../reference/frontmatter.ja.md)にあります。

```markdown
---
title: ガイド
description: 使い方
order: 20
---
```

## GitHubの記法

注意書き・脚注・図・タスクリスト・絵文字コードは、GitHubと同じように使えます。[ページの機能](../reference/features.ja.md)を見てください。
