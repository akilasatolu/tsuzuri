# ガイド

やりたいことに合うガイドを選んでください。

- **ページを増やしたい** → [ページを書く](./write-pages.ja.md): READMEからリンクを足すと、そのページがサイトに加わります。
- **見た目を変えたい** → [見た目を変える](./style.ja.md): ギャラリーでスタイルを選ぶか、配色だけを変えます。
- **日本語にも対応したい** → [多言語サイト](./multilingual.ja.md): ページの横に`*.ja.md`を置きます。
- **独自ドメインにしたい** → [公開の設定](./publish.ja.md): ブランチ・独自ドメイン・手動実行。
- **新しい版にしたい** → [更新する](./update.ja.md): コマンド1つで、設定はそのまま。
- **シェアされたときの見え方を整えたい** → [シェアと検索](./share-and-search.ja.md): OGP・favicon・sitemap・`llms.txt`。
