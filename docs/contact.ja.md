# お問い合わせ

質問や希望も、スタイルギャラリーへの掲載の依頼も、GitHub の Issue で受け付けます。

<p class="tsuzuri-hero-actions"><a class="tsuzuri-button tsuzuri-button-primary" href="https://github.com/akilasatolu/tsuzuri/issues/new">新しい Issue を作る</a><span class="tsuzuri-sep"> · </span><a class="tsuzuri-button" href="https://github.com/akilasatolu/tsuzuri/issues">Issue の一覧</a></p>

Tsuzuri の運営者は1人です。連絡を受ける場所は Issue だけなので、まずは Issue に書いてください。

## 質問や希望

質問・困りごと・希望は、[新しい Issue](https://github.com/akilasatolu/tsuzuri/issues/new) に、わかる範囲で次のことを書いてください。

- 何をしたか、何を期待したか、実際はどうなったか。
- Tsuzuri のバージョンと、実行したコマンド。
- 関係する `.github/tsuzuri/config` の部分。

書く前に、[FAQ](faq.ja.md) と既存の [Issue](https://github.com/akilasatolu/tsuzuri/issues) を見ると、答えが見つかることがあります。

## スタイルギャラリーに掲載してほしいとき

自分で作ったカスタムスタイルを[スタイルギャラリー](../gallery/style-gallery.ja.md)に載せたいときは、[新しい Issue](https://github.com/akilasatolu/tsuzuri/issues/new) に次のことを書いてください。

- **名前**: スタイルの名前(英語)。
- **URL**: スタイルのページからリンクするページ(たとえば、そのスタイルを使っているサイトや、スタイルのリポジトリ)。
- **画像**: スクリーンショットを1〜3枚(タイルにスライダーで表示します)。
- **説明**: 見た目についての1行の説明。
- **許可**: 画像と CSS ファイルをこのリポジトリ(`assets/gallery/`)に置いてよいか。あなたのサイトからリンクするのではなく、ここに置いて表示・配布します。

掲載が決まったら、運営者がスタイルギャラリーにタイルとスタイルのページを足します。タイルには画像がスライダーで表示され、クリックするとスタイルのページが開き、そこから CSS ファイルをダウンロードできます。
