# スタイル(Theming)

## 2層の仕組み(ベース + カスタムスタイル)

生成されるページの見た目(CSS)は、次の2つの層を順番に重ねて作られています。
後の層ほど優先度が高く、同じ詳細度のルールであれば後の層が先の層を上書きします。

```
1. ベース(base.css)       … 常に適用される。レイアウト幅・テーブル罫線・
                             コードブロックのpaddingなど、色を持たない構造ルールのみ
        ↓
2. カスタムスタイル(1つ)  … 配色+装飾。.github/tsuzuri/styles/ の中のCSSファイルで、
                             `THEME=ファイル名.css` で選ぶ(何も書かなければ default.css)
```

ベースは色を一切持たず、`color: var(--fg);`のようにCSSカスタムプロパティ(変数)を
参照するだけにとどめています。実際の色は2層目のカスタムスタイルが定義する変数によって
初めて決まります。変数を何も定義しないカスタムスタイル(コメントだけの`none.css`など)を
選ぶと、変数が未定義のままとなり、結果として色はブラウザの既定の見た目(黒文字・白背景など)
になります。

## カスタムスタイル

`.github/tsuzuri/styles/`に置く`○○.css`を、すべて**カスタムスタイル**と呼びます。`default.css`も、
ギャラリーでダウンロードしたものも、自分で作ったものも、同じ扱いです。サイト全体のカスタムスタイルは、
`.github/tsuzuri/config`の`THEME`キーに、**ファイル名だけ**(フォルダは書きません)を指定します。

```
THEME=glass.css
```

**カスタムスタイルは、配色だけでなく、リンクの下線の有無や見出しの太さ・行送りといった装飾も
含めてセットで切り替わる「視覚的なアイデンティティ」です**(配色のみを独立して
差し替える機能ではありません)。

- `THEME`を省略した場合・空にした場合は、`default.css`になります。
- `.css`のファイル名でない値(`none`、`material`のような昔のテーマ名、フォルダを含む値など)は、
  警告して`default.css`になります。
- ファイルが存在しない場合は、警告して、ベースだけでビルドします。
- ファイルは、常に`.github/tsuzuri/styles/`の中から読みます。`STYLE_DIR`の影響は受けません
  (`STYLE_DIR`はベースの場所だけです)。

### default.css(パッケージに入っています)

`default.css`は、Tsuzuri の標準のカスタムスタイルです。Material Design 3 風で、青系の配色、角丸のカードと影、
トーンのついたナビの選択が特徴です。ライト/ダークはOSの設定に合わせて自動で切り替わります。
パッケージに入っているので、`init`が(ベースの`base.css`と一緒に)`.github/tsuzuri/styles/`に置き、
設定ファイルも`THEME=default.css`で始まります。ダウンロードは要りません。
`init --update`で最新版に上書きされるので、編集したいときは別の名前にコピーして`THEME`で指定します。

### ギャラリーのカスタムスタイル

ほかのカスタムスタイルは、パッケージには含めて配りません。[ギャラリー](gallery.ja.md)に載せているので、
実際のページでの見た目を確かめて、CSSファイルをダウンロードして使います。
ダウンロードして`.github/tsuzuri/styles/`に置き、`THEME=ファイル名.css`にします。

- **グラス(`glass.css`)**: Glassmorphism。ゆっくり揺れて流れるオーロラの地に、色がそのまま透ける薄い透明なガラスのカード。
- **ニューモーフィズム(`neumorphism.css`)**: Neumorphism。地と同じ色の部品が、光と影で浮き出したりへこんだりする。
- **エディトリアル(`editorial.css`)**: 雑誌や上質なドキュメントのような、文字組と余白で見せるスタイル。大きな明朝体の見出しと章の番号、朱色の差し色。
- **ミニマル(`minimal.css`)**: Vercel や Linear のドキュメントのような、白・黒・グレーだけの落ち着いた見た目。リンクだけ青。
- **金継ぎ(`kintsugi.css`)**: 割れた器を漆と金で継ぐ「金継ぎ」のスタイル。白磁のようなカードに金の継ぎ目が走り、コードブロックは漆の黒。ライト表示は白磁、ダーク表示は黒漆。
- **ブループリント(`blueprint.css`)**: 設計図(青焼き)のような、青い地に白い方眼と細線、寸法線付きの見出し。常に同じ表示。
- **90年代(`nineties.css`)**: 90s Nostalgia。Windows 95 風の青緑のデスクトップと灰色のウィンドウ、立体のボタン。ライト表示のみ。
- **装飾なし(`none.css`)**: コメントだけのCSSファイル。ベースだけが適用され、色や装飾はブラウザの既定の見た目になります
  (`THEME=none`というキーワードはありません。`none.css`をほかのカスタムスタイルと同じように使います)。
- **Tsuzuri(`tsuzuri.css`)**: このサイト自身の見た目(下の囲みを参照)。

ライト/ダーク表示は、ブループリントが常に同じ表示、90年代がライトのみで、それ以外はOSの設定に合わせて
自動で切り替わります。グラスのガラス(背景のぼかし)は、ブラウザが対応していない場合は半透明のカードとして表示されます。

## ページ単位でカスタムスタイルを置き換える

`.github/tsuzuri/config`の`THEME`はサイト全体の既定値ですが、frontmatterの`theme`キーを使うと、
ページごとにカスタムスタイルを置き換えられます。`.github/tsuzuri/styles/`の中のカスタムスタイルの
ファイル名(`.css`で終わる名前だけ)を書きます。そのページには、ベースとそのファイルが使われ、
サイト全体のカスタムスタイルは混ざりません。装飾なしで表示したいページは`theme: none.css`にします
(コメントだけの`none.css`を`.github/tsuzuri/styles/`に置いておきます)。
詳しくは[Frontmatterリファレンス](frontmatter.ja.md#theme)を参照してください。

## 自分でカスタムスタイルを作る

`.github/tsuzuri/styles/`(`default.css`と同じフォルダ)に新しいCSSファイルを置き、そのファイル名を`THEME`に指定します。
配色を少し変えたいだけなら、**`default.css`を別の名前(例: `my.css`)にコピー**して、変数を書き換え、
`THEME=my.css`にします(`default.css`自体は`init --update`で上書きされるので、編集しません)。

各カスタムスタイルは`:root { --変数名: 値; }`という形でCSSカスタムプロパティを定義しています。
同じ変数名を書き換えることで、配色だけを差し替えることもできます。
主な変数は以下の通りです。

| 変数 | 意味 |
|---|---|
| `--fg` | 本文の文字色 |
| `--bg` | 背景色 |
| `--border` | テーブル罫線・区切り線の色 |
| `--accent` | リンクなどの強調色 |
| `--code-bg` | コードブロック・インラインコードの背景色 |
| `--font` | 本文のフォント指定(font-family) |
| `--content-width` | 本文カラムの最大幅(例: `860px`) |
| `color-scheme` | `light` / `dark` / `light dark`(OS設定に追従) |
| `--hl-keyword` / `--hl-string` / `--hl-number` / `--hl-title` / `--hl-attr` / `--hl-comment` | コードの色分けの色(キーワード・文字列・数値・関数名等・属性や変数・コメント)。未指定ならカスタムスタイルの`--accent`と`--fg`から自動で決まる |
| `--alert-note` / `--alert-tip` / `--alert-important` / `--alert-warning` / `--alert-caution` | 注意書き(`> [!NOTE]`など)の枠と見出しの色 |

> [!TIP]
> このサイト自体も、自分用のカスタムスタイル(「スレッド」のデザイン。
> [tsuzuri.css](https://github.com/akilasatolu/tsuzuri/blob/main/.github/tsuzuri/styles/tsuzuri.css))で見た目を作っています。
> 書き方の例として参考にしてください(見た目は[カスタムスタイルの例](gallery/tsuzuri.ja.md)で確認できます)。
>
> このサイトの[ギャラリー](gallery.ja.md)は、見本ページのfrontmatterに[`theme`](frontmatter.ja.md#theme)を
> 書いて、カスタムスタイルごとにそのスタイルだけの見た目で表示しています。

変数の上書きだけでなく、`main h1 { ... }`のような通常のCSSルールをカスタムスタイルに
直接書いて細部を調整することも可能です。カスタムスタイルはベースの後に
読み込まれるため、同じ詳細度であれば書いた内容が優先されます。

## ライト/ダーク表示に対応する

`NAV_ENABLED=true`のサイトでは、閲覧者がナビのボタンでライト/ダーク表示を選べます(v1.7.0以降)。
選ばれた表示は`<html data-theme="light">`または`<html data-theme="dark">`として付きます
(選んでいないときは付かず、OSの設定に従います)。

カスタムスタイルでダーク表示の色を書く場合は、「OSがダークモードのとき(ライト表示を選んだときを除く)」と
「ダーク表示を選んだとき」の両方に同じ色を書きます。`default.css`やギャラリーのカスタムスタイルもこの書き方です。

```css
/* ライト表示の色 */
:root {
  --fg: #1a1a1a;
  --bg: #ffffff;
}

/* ダーク表示の色 */
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) {
    --fg: #e5e5e5;
    --bg: #14161a;
  }
}
:root[data-theme="dark"] {
  --fg: #e5e5e5;
  --bg: #14161a;
}
```

`@media (prefers-color-scheme: dark)`の中に`:root`だけを書いた古い書き方でも表示は崩れませんが、
OSがダークモードのときに「ライト表示」を選んでも、その色はダークのままになります。
