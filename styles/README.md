# スタイル

ここには、生成されるページに当てる CSS が入っています。

- `base.css`(**ベース**): レイアウト幅、コードブロックの padding、テーブル罫線などの構造のルールだけを持ちます。配色そのものは含みません。
- `default.css`: Tsuzuri の標準の**カスタムスタイル**。Material Design 3 風で、ライト・ダークに対応します。パッケージに入っているので、ダウンロードは要りません。

ページの CSS は「ベース(`base.css`)→ カスタムスタイル1つ」の2層です。カスタムスタイルは、
`.github/tsuzuri/styles/` に置く `○○.css` のことで、`default.css` も、ギャラリーでダウンロードした
ものも、自分で作ったものも、すべて同じ扱いです。

**`init` と `init --update` が `.github/tsuzuri/styles/` に置くのは、`base.css` と `default.css` だけです。**
`glass.css` などほかのスタイルは配布しません。ギャラリーに載せているので、ダウンロードして使います。
`default.css` は `init --update` のたびに上書きされるので、編集したいときは別の名前にコピーして使います。

## 使い方

1. 使いたいカスタムスタイルをギャラリー(https://akilasatolu.github.io/tsuzuri/gallery/)でダウンロードし、
   `.github/tsuzuri/styles/` に置く(`default.css` は最初から置かれています)。
2. `.github/tsuzuri/config` の `THEME` に、そのファイル名を書く。

   ```
   THEME=glass.css
   ```

3. コミットして `TRIGGER_BRANCH` に指定したブランチに push すると、次回のビルドから反映されます。

`THEME` には、`○○.css` の**ファイル名だけ**を書きます(フォルダは書きません)。ファイルは
`.github/tsuzuri/styles/` の中から読み込みます(`STYLE_DIR` の影響は受けません。`STYLE_DIR` は
ベースの場所だけです)。`THEME` を書かない・空にしたときは `default.css` になります。`none` や
昔のテーマ名(`material` など)のように、`.css` のファイル名でない値は、警告して `default.css` になります。
ファイルが無いときは、警告してベースだけで続けます。

ベースだけの見た目にしたいときは、コメントだけの `none.css` のようなファイルを置いて、
`THEME=none.css` にします(`THEME=none` というキーワードはありません)。

ページごとに変えるときは、そのページの frontmatter に `theme: 名前.css` と書きます。
サイト全体の `THEME` のカスタムスタイルを置き換えます(混ざりません)。

## 自分でカスタムスタイルを作る

`default.css` を別の名前(例: `my.css`)にコピーして `.github/tsuzuri/styles/` に置き、
`THEME=my.css` にします。コピーした `:root { --変数名: 値; }` の部分は CSS カスタムプロパティの
定義なので、同じ変数名を書き換えると、配色だけを差し替えられます。

使える主な変数は以下の通りです。

| 変数 | 意味 |
|---|---|
| `--fg` | 本文の文字色 |
| `--bg` | 背景色 |
| `--border` | テーブル罫線・区切り線の色 |
| `--accent` | リンクなどの強調色 |
| `--code-bg` | コードブロック・インラインコードの背景色 |
| `--font` | 本文のフォント指定（font-family） |
| `--content-width` | 本文カラムの最大幅（例: `860px`） |
| `color-scheme` | `light` / `dark` / `light dark`（OS設定に追従） |

これらの変数は `styles/base.css` から `var(--fg)` のような形で参照されており、カスタムスタイルが
値を定義することで初めて配色が決まります。ベースだけ(`none.css` など)の場合は、これらの変数が
どこにも定義されないため、`base.css` 側の `var(--fg)` 等はブラウザの既定値にフォールバックします。

変数の上書きだけでなく、`main h1 { ... }` のように通常の CSS ルールを書いて、細かい見た目を調整する
こともできます(カスタムスタイルはベースの後に読み込まれるため、同じ詳細度であれば上書きされます)。

### 言語の切り替えボタン

多言語のサイト(`LANGUAGES` に2つ以上の言語を書いたとき)では、ページに言語の切り替えボタンが
出ます。カスタムスタイルで見た目を変えるときは、次のクラス名を使えます。

| クラス | 意味 |
|---|---|
| `.tsuzuri-lang-switch` | 言語のボタン(2言語のときのリンク、3言語以上のときのメニューを開くボタン) |
| `.tsuzuri-lang-menu` | 3言語以上のときのメニュー(`<details>`) |
| `.tsuzuri-lang-bar` | ナビが無いページで、本文の上にボタンを置く欄 |

言語のボタンは、カスタムスタイルの「メニュー」「ライト/ダーク」のボタンと同じ見た目になるよう、
カスタムスタイルの末尾の「言語の切り替え」のかたまりに同じ決まりを写しています。
ボタンの見た目を変えるときは、このかたまりも合わせて直してください。
