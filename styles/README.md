# スタイルプリセット

ここには、生成されるページに当てられる CSS テーマがいくつか用意されています。
好きなものを選ぶだけで、ページ全体の見た目が変わります。

**THEME は配色だけを決めるものではありません。** リンクの下線の有無、
見出しの太さや字間、行送り、`border-bottom` による強調表現など、配色と
密接に結びついた装飾も含めた「視覚的なアイデンティティ」をまとめて切り
替える仕組みです。テーマによっては、色だけを差し替えても同じ見た目を
再現できない装飾(たとえば下線をやめて `border-bottom` に変える等)が
含まれているため、あえて配色と装飾を分離せずセットで持たせています。

## 使い方

1. `.github/docs-pages.config` の `THEME` に、下表の中から好きなテーマ名
   (`material` / `glass` / `neumorphism` / `editorial` / `minimal` / `blueprint` / `nineties` / `none`)を指定する

   ```
   THEME=nineties
   ```

   （パッケージ初期状態のままなら `material`(マテリアル)が使われます）
2. コミットして `TRIGGER_BRANCH` に指定したブランチに push すると、
   次回のビルドから新しいテーマが反映されます

`THEME` を指定しなかった場合は `material`(マテリアル)が使われます。`THEME=none` を
指定した場合は、配色・装飾が一切適用されず、ブラウザの既定の見た目
(黒文字・白背景など)がそのまま使われます。

## 用意されているテーマ

| THEME値 | ファイル | 特徴 |
|---|---|---|
| `material`（既定） | `material.css` | マテリアル。Material Design 3 風の標準スタイル。青系の配色、角丸のカードと影、トーンのついたナビの選択。ライト/ダーク自動切替 |
| `glass` | `glass.css` | グラス。Glassmorphism。ゆっくり揺れて流れるオーロラの地に、色がそのまま透ける薄い透明なガラスのカード |
| `neumorphism` | `neumorphism.css` | ニューモーフィズム。Neumorphism。地と同じ色の部品が、光と影で浮き出したりへこんだりする |
| `editorial` | `editorial.css` | エディトリアル。雑誌や上質なドキュメントのような、文字組と余白で見せるスタイル。大きな明朝体の見出しと章の番号、朱色の差し色 |
| `minimal` | `minimal.css` | ミニマル。Vercel や Linear のドキュメントのような、白・黒・グレーだけの落ち着いた見た目。リンクだけ青 |
| `blueprint` | `blueprint.css` | ブループリント。設計図(青焼き)のような、青い地に白い方眼と細線、寸法線付きの見出し。常に同じ表示 |
| `nineties` | `nineties.css` | 90年代。90s Nostalgia。Windows 95 風の青緑のデスクトップと灰色のウィンドウ、立体のボタン。ライト表示のみ |
| `none` | （なし） | 配色・装飾を一切適用しない。ブラウザの既定の見た目になる |

## 自分でスタイルをカスタマイズしたい場合

`.github/docs-pages.config` の `STYLE_FILE` に独自の CSS ファイルを指定すると、
選んだ THEME の後に読み込まれる第3層として追記されます(THEME の内容を
上書きしたい場合はこちらを使います)。

各テーマファイルの `:root { --変数名: 値; }` の部分は CSS カスタムプロパティの
定義です。独自の `STYLE_FILE` の中で同じ変数名を書き換えることで、配色だけを
差し替えることもできます。

使える主な変数は以下の通りです。

| 変数 | 意味 |
|---|---|
| `--fg` | 本文の文字色 |
| `--bg` | 背景色 |
| `--border` | テーブル罫線・区切り線の色 |
| `--accent` | リンクなどの強調色 |
| `--code-bg` | コードブロック・インラインコードの背景色 |
| `--font` | 本文のフォント指定（font-family） |
| `--content-width` | 本文カラムの最大幅（例: `860px`） |
| `color-scheme` | `light` / `dark` / `light dark`（OS設定に追従） |

これらの変数は `styles/base.css`(基礎CSS。レイアウト幅やコードブロックの
padding、テーブル罫線などの構造ルールのみを持ち、配色そのものは含みません)
から `var(--fg)` のような形で参照されており、各テーマファイルが値を定義する
ことで初めて配色が決まります。`THEME=none` の場合はこれらの変数がどこにも
定義されないため、`base.css` 側の `var(--fg)` 等はブラウザの既定値にフォール
バックします。

変数の上書きだけでなく、`main h1 { ... }` のように通常の CSS ルールを
`STYLE_FILE` に追記して細かい見た目を調整することも可能です(追記した内容は
基礎CSS・THEME の後に読み込まれるため、同じ詳細度であれば上書きされます)。

### 言語の切り替えボタン

多言語のサイト(`LANGUAGES` に2つ以上の言語を書いたとき)では、ページに言語の切り替えボタンが
出ます。`STYLE_FILE` で見た目を変えるときは、次のクラス名を使えます。

| クラス | 意味 |
|---|---|
| `.tsuzuri-lang-switch` | 言語のボタン(2言語のときのリンク、3言語以上のときのメニューを開くボタン) |
| `.tsuzuri-lang-menu` | 3言語以上のときのメニュー(`<details>`) |
| `.tsuzuri-lang-bar` | ナビが無いページで、本文の上にボタンを置く欄 |

言語のボタンは、各テーマの「メニュー」「ライト/ダーク」のボタンと同じ見た目になるよう、
テーマファイルの末尾の「言語の切り替え」のかたまりに同じ決まりを写しています。テーマの
ボタンの見た目を変えるときは、このかたまりも合わせて直してください。
