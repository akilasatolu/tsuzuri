# スタイルプリセット

ここには、生成されるページに当てられる CSS テーマがいくつか用意されています。
好きなものを選ぶだけで、ページ全体の見た目が変わります。

**THEME は配色だけを決めるものではありません。** リンクの下線の有無、
見出しの太さや字間、行送り、`border-bottom` による強調表現など、配色と
密接に結びついた装飾も含めた「視覚的なアイデンティティ」をまとめて切り
替える仕組みです。テーマによっては、色だけを差し替えても同じ見た目を
再現できない装飾(たとえば下線をやめて `border-bottom` に変える等)が
含まれているため、あえて配色と装飾を分離せずセットで持たせています。

## 使い方

1. `.github/docs-pages.config` の `THEME` に、下表の中から好きなテーマ名
   (`wa` / `sakura` / `sora` / `akari` / `umi` / `none`)を指定する

   ```
   THEME=akari
   ```

   （パッケージ初期状態のままなら `wa`(和)が使われます）
2. コミットして `TRIGGER_BRANCH` に指定したブランチに push すると、
   次回のビルドから新しいテーマが反映されます

`THEME` を指定しなかった場合は `wa`(和)が使われます。`THEME=none` を
指定した場合は、配色・装飾が一切適用されず、ブラウザの既定の見た目
(黒文字・白背景など)がそのまま使われます。

## 用意されているテーマ

| THEME値 | ファイル | 特徴 |
|---|---|---|
| `wa`（既定） | `wa.css` | 和。浮世絵がテーマの江戸らしい標準スタイル。ライト/ダーク自動切替 |
| `sakura` | `sakura.css` | 桜。和・桜・墨を合わせたスタイル。ライト/ダーク自動切替 |
| `sora` | `sora.css` | 宙。満月の夜がテーマ。夜空に光の輪をまとった満月、月明かりの金色。常にダーク表示 |
| `akari` | `akari.css` | 灯。暗闇に灯る灯籠がテーマ。夜の闇の地に、灯籠の琥珀色の灯り。常にダーク表示 |
| `umi` | `umi.css` | 海。江戸の海がテーマ。藍と浅葱色に、北斎のような波頭と千鳥。ライト/ダーク自動切替 |
| `none` | （なし） | 配色・装飾を一切適用しない。ブラウザの既定の見た目になる |

## 自分でスタイルをカスタマイズしたい場合

`.github/docs-pages.config` の `STYLE_FILE` に独自の CSS ファイルを指定すると、
選んだ THEME の後に読み込まれる第3層として追記されます(THEME の内容を
上書きしたい場合はこちらを使います)。

各テーマファイルの `:root { --変数名: 値; }` の部分は CSS カスタムプロパティの
定義です。独自の `STYLE_FILE` の中で同じ変数名を書き換えることで、配色だけを
差し替えることもできます。

使える主な変数は以下の通りです。

| 変数 | 意味 |
|---|---|
| `--fg` | 本文の文字色 |
| `--bg` | 背景色 |
| `--border` | テーブル罫線・区切り線の色 |
| `--accent` | リンクなどの強調色 |
| `--code-bg` | コードブロック・インラインコードの背景色 |
| `--font` | 本文のフォント指定（font-family） |
| `--content-width` | 本文カラムの最大幅（例: `860px`） |
| `color-scheme` | `light` / `dark` / `light dark`（OS設定に追従） |

これらの変数は `styles/base.css`(基礎CSS。レイアウト幅やコードブロックの
padding、テーブル罫線などの構造ルールのみを持ち、配色そのものは含みません)
から `var(--fg)` のような形で参照されており、各テーマファイルが値を定義する
ことで初めて配色が決まります。`THEME=none` の場合はこれらの変数がどこにも
定義されないため、`base.css` 側の `var(--fg)` 等はブラウザの既定値にフォール
バックします。

変数の上書きだけでなく、`main h1 { ... }` のように通常の CSS ルールを
`STYLE_FILE` に追記して細かい見た目を調整することも可能です(追記した内容は
基礎CSS・THEME の後に読み込まれるため、同じ詳細度であれば上書きされます)。
