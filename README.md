This branch (`main`) is where Tsuzuri itself is developed: the setup CLI, the build scripts and the theme CSS. The `init` command that users run fetches its files from this branch.

**To learn how to use Tsuzuri, see the user documentation: https://akilasatolu.github.io/tsuzuri/**

That site is built with Tsuzuri from the `docs` branch.
